# GeminiBox

סקריפט [Tampermonkey](https://www.tampermonkey.net/) לשיפור הממשק של [ג'מיני](https://gemini.google.com/app/).

להתקנת הסקריפט החדש שמצמצם אוטומטי בלוקי קוד, מוסיף כפתור הורדת כל קבצי ההודעה, ומוריד את קבצי הקוד בשם המקורי (כולל כפתור מסגרת צבעוני המסמן את סיום כתיבת הבלוק):

https://github.com/Tzadikvtovlo/GeminiBox/raw/refs/heads/main/GeminiBox.user.js

להתקנת הסקריפט הישן, לצמצום בלוקי הקוד בלבד:

https://github.com/Tzadikvtovlo/GeminiBox/raw/refs/heads/main/t/Tampermonkey.user.js
